# Nexa Digital — Digital Marketing Agency Website

## Future Interns UI/UX Design Task 1

Nexa Digital is a modern digital marketing agency website concept designed to help small businesses, startups, and personal brands understand digital marketing services and easily get in touch for a consultation.

## Project Objective

The goal of this project was to design a professional, user-friendly website focused on clear communication, trust, and lead generation.

## Target Audience

- Small businesses
- Startups
- Personal brands
- Businesses looking to grow their online presence

## Main Pages & Sections

- Homepage
- Services
- Work / Case Studies
- Results
- About
- Contact / Lead Generation

## Key UX Decisions

- Clear value proposition on the homepage
- Strong and visible "Free Consultation" calls-to-action
- Simple navigation
- Service-focused content
- Trust and results sections
- Testimonials
- Lead-generation contact form
- Responsive and professional visual design

## Tools Used

- Figma Make
- GitHub

## Design Style

The website uses a modern agency-style visual direction with a dark navy background, bright turquoise accents, clean typography, and spacious layouts to create a professional and premium feel.

## Project Note

Nexa Digital is a fictional concept created for the Future Interns UI/UX Design Task 1. Any statistics, testimonials, client names, and case-study results shown in the design are illustrative/demo content and do not represent real client data.
